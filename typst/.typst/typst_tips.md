# Typst 記述の知見とTips

このドキュメントは、Typstでレポートを作成する過程で得られた、意図しないレイアウト崩れの解決策をまとめたものです。

## 1. 意図しないインデント（字下げ）の防止
Typstでは段落が切り替わると、テンプレートの設定（`par(first-line-indent: 1em)`など）によって自動的に先頭が字下げされます。
`*回答:*` や `*(a)*` といった「見出し風のテキスト」を字下げさせたくない場合に、単に改行や空行を入れるとインデントされてしまい、見た目が不格好になります。

**解決策:**
段落の字下げルールを回避しつつ、見出しとして適切な上下の余白（マージン）を持たせるには、カスタム関数を作成して `#block` 要素で囲むのが最適です。
`===` のような標準見出しを使うと目次（TOC）が汚染されてしまいますが、この方法なら目次にも影響しません。

```typst
// 定義例
#let label_heading(title) = block(
  above: 1.5em,
  below: 0.8em,
  text(weight: "bold", title)
)

#let sub_label(title) = block(
  above: 1.2em,
  below: 0.5em,
  text(weight: "bold", title)
)

// 使用例
#label_heading([問題:])
与えられた行列...

#label_heading([回答:])
#sub_label([(a)])
数式...
```


## 2. リスト内の強制改行（バックスラッシュの必要性）
`-` (箇条書き) や `1.` (番号付きリスト) といったリスト項目の中で改行したい場合、エディタ上で単に改行しただけではTypstはそれを「同一行」として結合してしまいます。
逆に空行を挟むと、別の段落や別のリスト要素と認識され、インデントやマージンが崩れる原因になります。

**解決策:**
リストの同一項目の中で改行（強制改行）を行いたい場合は、行末に `\` (バックスラッシュ) を記述する必要があります。

```typst
- *1位: El Capitan (米国)*
  構成要素: 1ノードあたり AMD Instinct MI300A (APU) を4基搭載。\
  コア(1CU)あたり: MI300Aの1CUあたりFP64演算器を64基搭載。\
  チップ(APU)あたり: 1基あたり228CU。
```
行末に `\` をつけることで、過剰な段落間隔を空けずに綺麗に折り返すことができます。
