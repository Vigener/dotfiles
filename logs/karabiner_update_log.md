# Karabiner-Elements 設定更新ログ - 英数+YへのCmd+Yの割り当て検討

## 1. ユーザー要望の確認
- 要望: 「英数キー+Yに対して、 [Cmd+Y]を設定することを検討しています。どうですかね？まずは実装前に妥当性などを検討して。」

## 2. 現状調査
- `rules/sys.ts` を確認: 英数キーは押し下げることで `eisuu_pressed = 1` になり、他のキーと組み合わせることで英数レイヤーとして機能している。
- `rules/edit.ts` を確認: 現在、英数レイヤー (`eisuu_pressed = 1`) において `y` キーにはマッピングが定義されていない。
- `rules/launcher.ts` を確認: 「かなキー＋Y」には `mute` が割り当てられているが、英数キーとは独立しているため競合しない。
- `README.md` を確認: 英数レイヤーのマッピング表に `Y` の記載はない。

## 3. 妥当性の検討
- **操作の一貫性**:
  - `edit.ts` には、すでに `w, z, x, c, v, n, a, e, g, r, t, p, b` などのアルファベットキーが `Cmd + アルファベットキー` にマッピングされている（例: `英数+c` -> `Cmd+c`）。
  - `英数+y` -> `Cmd+y` は、この既存のデザインパターン（Cmdショートカットの模倣）に完全に合致し、一貫性を保てる。
- **Cmd+Y の主な用途と利便性**:
  - **ブラウザでの履歴（History）表示**: ChromeやVivaldi、Safari等のブラウザで `Cmd+Y` は「履歴」を開く標準ショートカット。英数キー（左手親指）＋ Y（右手人差し指）という押しやすいコンビネーションで即座に呼び出せるため、利便性が向上する。
  - **やり直し (Redo)**: Microsoft Officeやその他のクロスプラットフォームアプリケーションにおいて、`Cmd+Y` は「やり直し (Redo)」の役割を果たす。`英数+z` (Cmd+Z / Undo) と対になる操作として、ホームポジション付近でスムーズに実行可能になる。
  - **Finderでのクイックルック**: Finderで `Cmd+Y` はクイックルック（スペースキーでも可能だが標準の代替）として機能する。
- **入力負荷**:
  - 左手親指で「英数」をホールドし、右手人差し指で「Y」を打鍵する動きは、両手に荷重が分散するため非常に打ちやすい。
- **結論**:
  - 競合もなく、操作の一貫性および実用性の観点から「設定は非常に妥当かつ有用である」と判断。

## 4. 追加要望の確認（英数+Enter -> Cmd+Enter）
- 要望: 「もう一つ、英数キー+Enterを[Cmd+Enter]にすることの妥当性はどうですか？」

## 5. 英数+Enter の妥当性検討
* **物理キーとしての操作性（英数＋物理Enter）**:
  - JIS配列キーボードでは、左手親指の「英数」キーと、右手小指の「Enter」キーを同時押しすることになる。
  - これは通常の「左Command + Enter」の同時押しと手の動きや負荷がほぼ全く同じ（キー1個分のズレのみ）。
  - そのため、物理Enterキーを使う前提であれば、あえてKarabinerでマッピングを追加するメリットは少ない。
* **ホームポジションでの操作性（英数＋セミコロンでCmd+Enterを代用するか）**:
  - `edit.ts` では `英数 + ;` が修飾キー付き（Shift, Ctrl, Opt）のときだけ `Enter` になるように定義されているが、修飾キーなしの `英数 + ;` は `Enter` ではなくそのまま `;`（セミコロン）が入力される設計。
  - もし「ホームポジションから動かさずに Cmd+Enter を入力したい」という意図であれば、`eisuu + Command + ;` を `Cmd+Enter` にマッピングする、あるいは `eisuu + ;` 自体を `Enter` にマッピングする（ただしセミコロンの直接入力が英数レイヤーでできなくなるトレードオフあり）などの設計変更が必要。
* **ユースケース**:
  - `Cmd+Enter` はSlack等のチャット送信、VSCode等での「下に行を挿入」などで多用されるため、ショートカット自体の重要度は極めて高い。
* **結論**:
  - 物理Enterキーを押す想定であれば、標準の `Cmd+Enter`（左Command+Enter）で十分代用可能。
  - もしホームポジション（セミコロンキー等）で完結させたい意図であれば、マッピングの追加を検討する価値があるが、キー競合やトレードオフを整理する必要がある。
