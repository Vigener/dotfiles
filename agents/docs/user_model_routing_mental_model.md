## 1. 五十嵐さんの最新メンタルモデル（生の声・正本）

2026年10月中旬時点でのサブスクリプション契約状態（**Cursor Pro** 主軸 ＋ **Google AI Pro (agy)** 並走）に基づいた、各モデルの使い分け・実運用の認識。

### 契約の経緯とスタミナ枠（2026-10-14 更新）
- **Cursor Pro の維持決定**: Claude Pro への乗り換え検討、続いて ChatGPT Plus への乗り換え検討を経て、xAI サブスク統合の動向や利用実績を踏まえ、**既得権益化した Cursor Pro サブスクを維持**することに決定。
- これにより、Cursor Pro 枠の **Grok 4.6 / 4.7** が、Google AI Pro の **Gemini 3.8 Flash** と同程度に「ほぼ量を気にせず叩ける主軸スタミナ枠」として安定運用されていた。
- **【2026-10-16 状況変化】Cursor Pro 残枠 6.4% 逼迫 ＆ agy Argon 正式解放**:
  - Cursor Pro 枠の急激な枯渇を受け、Grok 4.7 に背負わせていた「日常の思考・設計・オーケストレーション」を、agy の **Gemini 4 Argon 独立週枠** へ全量オフロードする方針を確立。

### ① Cursor Pro 主軸モデル

- **Grok 4.6 / 4.7**:
  - 研究などを中心に Cursor Pro サブスクである程度たくさん使えるメインの一つ。
  - オーケストレーションも基本こいつに頼むことが多かった。
  - ※ただし Cursor Pro 残枠が逼迫している局面では、思考・設計タスクを agy 側の Argon へ委譲し、Cursor 枠を温存する。
- **Composer 2.5**:
  - コーディング用（`agent --model composer-2.5`）。
  - 高度なコーディングの場合は、Argon に詳細仕様書・擬似コードを書かせたうえで投げ、打鍵作業員に徹させる。
- **Claude Sonnet 5.5**:
  - 日常的にある程度信頼度が欲しい相談をする時用。
  - Opus 5.5 などにもほぼ肉薄しているという認識。
- **Claude Opus 5.5**:
  - 研究における重要な意思決定などのときには敵対レビュー役として使用を検討。
- **Claude Fable 5.1**:
  - メタ認知力、発想の広げ方が強いという認識。
  - Opus 以上に一瞬で Cursor Pro のクレジットを溶かすため、週あたりの利用回数を厳密に管理（温存対象）。「情報は揃っているが行き詰まっている」時や根本的な設計のブレイクスルーに使用。
- **GPT-5.6 Terra**:
  - 安くはないが、コスパ寄りの「敵対レビュー」用。Claude とは違う方向性の意見を入れたい時など。
- **GPT-5.6 Sol**:
  - 基本は高くて使えないが、Fable と同じく最高峰ブレイクスルーの候補。

### ② Google AI Pro (agy) 主軸モデル ＆ Web Gemini

- **Gemini 3.8 Flash**:
  - life-brain など研究以外の日常寄りのメイン、およびリポジトリ全体の探索用。
  - 割とたくさん使えるし、5時間制限＋1週間制限で回復するため気にせず使える。
  - コンテキストが長く持てる（1Mトークン）。ディレクトリの大規模探索（Task: Extract）や高速調査に最適。
- **Claude Opus 5.5 (Thinking) / Claude Sonnet 5.5 (Thinking) 【2026-10-14 更新】**:
  - Google AI Pro 側で利用可能な Claude モデルが 4.6 から **Opus 5.5 / Sonnet 5.5** に更新。
  - **Weekly limit の消費感覚**: ファイルを読ませながら発想させるタスクなどで、**Opus 5.5 が約10%/回**、**Sonnet 5.5 が約5%〜** の感覚。
  - 以前（4.6時代）の「最高峰の知能の利用回数に強い制約がある」という切迫感は大きく緩和され、実用的に叩きやすくなった。ただし無尽蔵ではないため、重要な局面での深い思考や敵対的レビューに充てる。
  - **※絶対禁止**: 間違えて `cursor-agent --model claude-opus-5.5` で呼ぶのは絶対にしない（Cursor 側クレジットの無駄遣い防止。agy 側枠で消費する）。
- **Gemini 4 Argon (`gemini-4-argon`) 【2026-10-16 改定：agy 正式解放 ＆ 週次バーンダウン原則確立】**:
  - **【重大マイルストーン】Antigravity CLI (agy) で Google AI Pro 契約者向けに「Argon 独立週枠（別クォータ）」が正式提供開始**:
    - Gemini Models (Flash / Pro) の枠を一切消費せず、**完全に独立した 100% 週リミット** として agy に常備された。
    - これにより、Web 画面へコピペ往復することなく、**agy のハーネス内でローカルリポジトリの全コードや Git 差分を直接食わせながら、DeepSWE 77.9%（1位）・LABBench 88.8% の最強推論を回せる** ようになった。
  - **【週枠消化（Burn-down）の行動原則】Use it or lose it（使わなければ廃棄損）**:
    - 従量課金API（使わないほど節約）とは異なり、Argonの週枠は翌週に繰り越されない。**リセット時に枠を残すのはサブスク代（月額¥1,280）の権利を捨てた状態（純損失）** である。
    - したがって「高難度の設計・数理検証のときだけ温存して使う」のではなく、**「日常業務の前線に配置し、毎週100%きれいに使い切る（バーンダウンする）」** 積極投資型ルーティングへ転換する。
  - **Argonの日常4大門番（Gatekeeper）タスク**:
    1. **実装前（詳細仕様化・擬似コード策定）**: Composerに大雑把に投げる前に、Argonに「競合状態・例外系・型安全・エッジケース」を織り込んだ完全仕様を書かせる。
    2. **実装後（敵対的コード監査 / Adversarial Audit）**: Composerが生成したGit DiffをArgonに食わせ、「不要な計算量・メモリリーク・境界値の破綻」を容赦なく指摘・検収させる。
    3. **テスト作成（意地悪な境界値テスト）**: 「このモジュールをクラッシュさせる境界値・極限入力の単体テストを書いて」と指示し、テストスイートを強靭化する。
    4. **調査・サーベイ（批判的読解）**: Flashが収集した文献や技術仕様に対し、Argonに「前提の穴・論理の飛躍・自研究への適用限界」を深く監査させる。
  - **二段構えの Argon 運用規律**:
    1. **第一線（コード直結設計・敵対監査・バーンダウン）**: **agy 内の Argon 独立枠** を最優先利用。リポジトリの日常品質門番として毎週使い切る。
    2. **第二線（無尽蔵フォールバック）**: agy 側の週枠を使い切った場合、または広域の論文サーベイや巨視的ブレストには、**Google AI Pro 付属の Web 版 Argon（無料）** へフォールバックして制限を恐れず使い倒す。
  - **卒研B 中間報告（10/19 送付週）の例外**: 本線レビューは思考レベル **中**。**高** は 10/20 赤入れと、本文に載せない数理メモだけ。通読後 1 往復を予算にする。正本は `inbox/ORCH_ARGON_ADOPTION_2026-10-14.md`。
  - ディレクトリの大規模探索・泥臭いファイル全走査などトークン量を激しく消費するタスクは、引き続き無尽蔵の 3.8 Flash が適任。設計・推論・仕様化・監査に Argon を充てる。
- **Gemini 3.1 Pro**:
  - ナンバリングが進まず、3.8 Flash や Argon に挟まれてポジション喪失。現在あえて選ぶ動機はほぼない。

## 4. 従量課金API（OpenRouter / DeepSeek）に関する検討記録 (LIFE-26)

**ステータス**: **保留・見送り（Grok 4.7 敵対レビューおよびユーザー裁定により棄却）**  
**チケット**: [LIFE-26](https://linear.app/mikoto-hq/issue/LIFE-26/deepseek-api残高消化後にopenrouterを試用移行検討)

### 4.1 検討の背景と「真の懸念」の言語化
- **発端**: 唯一の従量課金APIである DeepSeek Platform の残高が残り $0.93 となり、枯渇後の乗り換え先として OpenRouter（Claude Haiku 5.5 や DeepSeek V4.1 Flash のスポット併用）を検討した。
- **真の不安の正体**:
  - Cursor Pro 枠の **Grok 4.7 の利用枠が想定より早いペースで消費されており、「月途中で使い切った後にどうしよう」という不安** が根底にあった。
  - そのため、「Grok が切れた際の保険・受け皿」として軽量従量モデルの事前配備を模索していた。

### 4.2 Grok 4.7 による敵対的レビューの結論（要約）
2026-10-14、`cursor-agent --model grok-4.7-high` による忖度なしの敵対レビューを実施。結果は **「全面棄却」**。

1. **手持ちの定額モデルによる「完全支配」**:
   - 批判的論理検証（セカンドオピニオン）は、すでに Cursor Pro 枠の Grok 4.7 や Google AI Pro 枠の Opus/Sonnet 5.5 Thinking が最高峰で担っており、軽量な Haiku 5.5 を呼んでも「ノイズ」にしかならない（このレビューを Grok 自身が定額枠で完結させていること自体が不要の証拠）。
   - HPC実装で Composer が詰まった難所において、軽量な Flash に落としても能力の引き上げにはならず、同じ失敗を再抽選するだけ。
2. **OpenRouter の隠れた不都合**:
   - DeepSeek 公式のオフピーク 50% 割引が失われる（ピーク単価 $0.30/$1.20 固定）。
   - 29 社のサードパーティホストへ分散するため、生成物の品質揺らぎや機密コード送信経路のブラックボックス化を招く。
3. **過剰最適化（Bikeshedding）の罠**:
   - $0.93（約140円）の端数を無駄にしないために、複数の API・ルーティング・キー管理を抱え込むこと自体が、最大の「認知的負債（意思決定コストの浪費）」。

### 4.3 採用された方針（運用の決定）

1. **現時点での OpenRouter 移行は見送り**:
   - DeepSeek Platform の残り残高（$0.93）は現場スクリプト等で使い切るか放置とし、終了後は **「従量課金口座は一度クローズ（ゼロ化）」** する。
   - サブスク 2本（Google AI Pro ＋ Cursor Pro）のみの、最も身軽で脳内負荷ゼロの運用を維持する。
2. **再検討のトリガー条件（「その時」が来たら動く）**:
   - 事前に従量モデルを過剰設計・準備しない。
   - **「実際に月末などで Grok 4.7 の枠が枯渇し、かつ Gemini 3.8 Flash や Google AI Pro 側のモデルでは代替できない難所に直面した」という事実が発生した瞬間** に初めて、次の一手（スポットAPIの導入や追加チャージ）を検討する。

3. **【2026-10-15〜16 発動】Cursor Pro 枠逼迫 ＆ agy Argon 正式解放による新体制**:
   - Cursor Pro 枠が残り 6.4%（更新まで7日）と逼迫し、agy 側の Claude/GPT 週次枠がリセット待ちとなったため、Anthropic 公式 API（$5 デポジット・Auto-reload OFF・Claude Code CLI）をスポット配備。
   - **直後の 2026-10-16、Antigravity CLI で Google AI Pro 契約者向けに「Gemini 4 Argon 独立週枠」が正式解放**。
   - これにより、有料の Anthropic API を叩く前に、**「agy 内の Argon 独立枠（無料）」でコード直結の超高度設計を回せる最強の第一防壁が完成**。
   - さらに「Use it or lose it」の行動経済学に基づき、**「Argon 週次バーンダウン運用規律（日常4大門番）」** を確立。有料APIを温存しつつ、定額週枠を100%使い切る最適布陣へ進化。詳細は [[subscription_and_api_playbook_2026-10]] を参照。
