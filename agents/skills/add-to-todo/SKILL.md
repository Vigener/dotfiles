# add-to-todo

作成したばかりの Wiki / Markdown / HTML を、あとで読むタスクとして `now/TODO.md` に登録する。

## 手順

1. このセッションで新規作成または大きく更新した成果物のパスと概要を特定する。
2. ワークスペース直下の `now/TODO.md` を読む。無ければ作らない（先にユーザーへ確認）。
3. 指定がなければ `## いつか・気になること` の末尾。今日やるものなら `## 今日`、今週なら `## 今週`。節が無ければその見出しを足す。
4. 次の形で追記する。パスは `file:///` の絶対パス。

```markdown
- [ ] 直近で作成した資料（〇〇など）を読む・確認する
  - [ ] [ファイル名](file:///絶対パス)
```

5. どの節に何を足したかを短く報告する。

## やらないこと

- 完了済みチェックを外す
- TODO 全体の並べ替え
