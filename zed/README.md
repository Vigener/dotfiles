# Zed Tips & Settings

Zedエディタをより便利に使うためのTipsやショートカットをまとめています。

## 便利なショートカット

### 🔍 集中モード (ペインの最大化)
- **`Shift + Esc`**
  現在フォーカスが当たっているペイン（エディタタブやターミナルなど）を最大化（ズーム）し、そのペインのみを画面いっぱいに表示します。他のペインが非表示になるため、特定のファイルの編集に集中したいときに非常に便利です。もう一度 `Shift + Esc` を押すと、元の分割レイアウトに戻ります。

### 📝 アウトライン検索 (シンボル・見出しのジャンプ)
- **`Cmd + Shift + O`**
  開いているファイル内の見出し（Markdownのヘッダーや、コード内のクラス・関数など）を抽出し、画面中央にモーダル（ポップアップ）で表示します。
  表示された状態でそのまま文字を入力すると、見出しを素早く絞り込み検索でき、Enterキーで目的の箇所へ瞬時にジャンプできます。
  
  > **Note**: `Cmd + Shift + B` を使用すると左側のサイドバーパネルにアウトラインを常時表示させることもできますが、画面を広く使いつつ、キーボード操作でサクサク移動したい場合は、こちらのモーダル表示（`Cmd + Shift + O`）の方がおすすめです。

## 独自キーバインド (keymap.json)

VSCodeの操作感に寄せつつ、ペインやパネルの切り替えを `Ctrl + Shift` ベースに統一することで、思考を途切れさせずに画面操作ができるようにカスタマイズしています。

### 🗂️ パネル・ペインのフォーカス切り替え
`Ctrl + Shift + [キー]` の組み合わせで、各パネル・ペインへのフォーカス移動を直感的に行えるようにしています。
（※デフォルト機能と競合するエディタの `Ctrl + Shift + E` （行末まで選択）は無効化しています。）

- **`Ctrl + Shift + E`**: 左サイドバー (Project Panel / エクスプローラー) のトグル・フォーカス
  - **理由**: VSCodeのエクスプローラー表示 (`Cmd/Ctrl + Shift + E`) の操作感に合わせるため。(`E` は Explorer の E)
- **`Ctrl + Shift + C`**: 中央のメインエディタ (Center Pane) へのフォーカス
  - **理由**: 他のパネル（サイドバーやAIパネルなど）で作業した後に、すぐにコード編集に戻るため。(`C` は Center の C)
- **`Ctrl + Shift + R`**: 右ドック (Right Dock / 主にAI Agent Panelなど) のトグル
  - **理由**: Zedの強力なAIパネルなどをサッと呼び出し・非表示にするため。左サイドバー(`E`)・中央エディタ(`C`)・右ドック(`R` / Right) という位置関係でキーを割り当て、直感的にしています。

> **Note**: これらのキーバインドは `Workspace` だけでなく `AgentPanel` コンテキストでも有効化されているため、AIパネルにフォーカスがある状態からでも、一発でエクスプローラーやエディタへ戻ることができます。
